## Hypothesis and proof before evaluation
H1: caching root count once and zero-child counts per parent input prefix preserves each exact lexicographic rank result and all transcript multiplicities. Let c(p) count accepting completions. The false subtree has c(p0) models. Choose false iff rank<c(p0); otherwise subtract c(p0) and choose true. Counts depend only on immutable CNF and prefix, not query order, so reusing the exact stored integer is semantics preserving by induction. Unused declared bits remain in counts; gates are parsimonious auxiliaries, never prior bits. Impossible events must still raise ImpossibleEvent. No observer-specific closed form will be used.

H2: complete enumeration requires 1+P actual CNF calls, where P is the number of distinct proper prefixes visited by accepted tapes; old method requires 1+C(n+1) calls for C accepted tapes, excluding explicit impossible-event probe. In particular T=8 unrestricted: C=512, n=9, P=511, so 512 versus 5121 calls. For empty event P=0; cached probe adds no underlying count, old probe adds one. Cache stores P tuples of length at most n-1 and P integers; worst-case exponential memory O(n*2^n) bits/tuple slots, not polynomial. CNF counting remains exponential; prefix reuse does not remove worst-case counting complexity. Root recounts dominate old cost: at least C repeated root solves are removed. Exhaustive transcript output itself takes Omega(C*T) work with this representation.

H3 (descriptive performance): on this host candidate full compile/count/all-ranks/replay/multiset wall time is lower than original at T=8 unrestricted. No prediction of beating forward. Report ratio against contemporaneous forward, not only historic 0.001790 s. Retain a negative finding if candidate loses.

Timing excludes output serialization and independent checking; those are in process wall time. Also record separately exact-count contract; do not confuse it with multiset contract.

Each method/cell in fresh child process, serial execution. 60 sec/cell/method, 512 MiB address space, total 600 sec. Preserve timeout/error/stdout/stderr rows; planned denominator 48. No early success stop. Baseline/candidate order alternates by cell index; forward first. Baseline original evidence never rerun in place. Record full counters, priors, support, actual CNF calls, count requests/cache hits/entries/key slots, rank requests, replay ticks, enumerated tapes, gates/clauses/literals, wall/CPU/RSS and host. RSS is process peak, not incremental cache memory; cache shallow recursive object-size estimate separately labeled, not a substitute for RSS.
